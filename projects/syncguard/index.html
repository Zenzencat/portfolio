SyncGuard

GNSS spoofing and jamming detection for 4G/5G base-station timing

Built entirely by me (Team Leader · ML/AI Lead).

  • Python
  • scikit-learn
  • SHAP
  • FastAPI
  • PySAL
  • SQLite
  • Docker

What it is

A software-first GeoAI shield that detects GNSS spoofing against base-station timing, maps incident spread across tower networks, prioritises threat areas, and supports resilient operator response without requiring hardware replacement.

Why

4G/5G base stations rely on GNSS timing for TDD, inter-cell coordination and handover. Spoofing feeds a receiver a false time and silently degrades the network, with no outage alarm. Most receivers cannot authenticate the signal, so detection must use what off-the-shelf receivers already report.

How it works

  1. Extract 23 receiver features per ~1 Hz epoch
  2. RandomForest attack-vs-clean detector, split by recording
  3. FastAPI service with a SHAP explanation per prediction
  4. Hysteresis alerts — 3 readings to raise, 5 to clear
  5. Moran's I / LISA hotspots on 136 real towers (simulated spread)
  6. Live dashboard + replay; one-command Docker deploy

Results

Measured on the public JammerTest 2024 dataset — real u-blox receiver logs under real jamming, spoofing and meaconing attacks at a controlled test range in Norway — the model reached 87.7% accuracy and 93.7% attack recall on 8 held-out recordings unseen in training.

Limitations: Clean-class recall is only 66.7%, and test-range receivers are not 4G/5G base-station timing hardware, so transfer to base stations is unvalidated.
