Autonomous Pick-and-Place Robot

Vision-guided 4-DOF robot arm: YOLOv8 colour scan, base rotation and preset motion sequences

Team project · my role: robot architect (vision and arm integration), arm motion sequences and base-rotation logic, field tuning under competition conditions.

  • YOLOv8
  • OpenCV
  • Preset motion sequences
  • pyfirmata2
  • Arduino

What it is

An autonomous pick-and-place robot: a camera and YOLOv8 scan for objects by colour, the 4-DOF arm's base rotates to each object's position, and preset motion sequences (pick, grab, lift, place) run through an Arduino.

Why

The task was logistics-style pick-and-place: picking up objects and placing or stacking them in the right positions, which is exactly what real warehouse robots have to do.

How it works

  1. Scan the area with the camera and detect objects by colour with YOLOv8
  2. Convert each detected object's position into a base rotation angle
  3. Run preset motion sequences (pick, grab, lift, place) on 5 servos through an Arduino (pyfirmata2)
  4. Field testing & competition runs

Limitations: I started an inverse-kinematics solver but did not finish it in time for the competition, so the arm used preset motions and could adapt to object positions only in a limited way.
