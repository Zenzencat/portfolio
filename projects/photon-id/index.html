Photon ID

Corneal-glint liveness detection that defeats deepfakes using the physics of light

Team project · my role: demo build and final-round presenter to the Samsung / KBTG judging panel.

  • Python
  • OpenCV
  • MediaPipe
  • HMAC-SHA256

What it is

A physics-first liveness check. The screen flashes a randomised sequence of coloured lights at the user's face, the camera captures the corneal glint (the tiny reflection on each eye), and the system checks that the right colour appears with physiologically plausible latency. Printed photos, screen replays, video loops and deepfake streams can't react to the challenge in real time.

Why

Most anti-spoofing systems rely on ML models that can themselves be fooled by sophisticated deepfakes. Photon ID verifies liveness from corneal optics instead of a trained spoof classifier.

How it works

  1. Random colour challenge sequence, no two consecutive flashes alike, with black calibration frames
  2. Corneal-glint capture from face landmarks
  3. Colour-dominance and latency-window checks with an adaptive (EWMA) latency model
  4. Stagnation detector for frozen or looping video
  5. HMAC-SHA256 attestation packet simulating a hardware-backed signature
